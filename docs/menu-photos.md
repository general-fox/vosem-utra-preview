# Фотографии завтраков

Фотографии взяты из меню кофейни «Восемь утра» в Яндекс Картах 28 сентября 2026 года. Адрес страницы и точные URL использованных оригиналов записаны в `menu-photo-sources.json` рядом с этим документом. Все 13 доступных фотографий получены в размере `orig`; фотографии для остальных шести блюд не подменяются похожими изображениями.

Для сайта оригиналы преобразованы в WebP с качеством 85. Максимальные ширина и высота — 960 пикселей, пропорции сохранены; маленькие оригиналы не увеличиваются. Содержание и кадрирование фотографий не изменены. Общий размер файлов: **497 410 байт** вместо **6 036 523 байт** у оригиналов (на 91,8% меньше).

## Повторная подготовка

Нужны Python 3 и Pillow. Из корня проекта:

```powershell
python scripts/optimize-menu-photos.py --download-missing
```

Скрипт загружает только адреса из файла источников, создаёт `public/menu-images/*.webp` и обновляет пути в `public/data/menu.json` и параметры фотографий в `docs/menu-photo-sources.json`. Рабочее меню сервера `.data/menu.json` он не меняет.

Если оригиналы уже сохранены средствами браузера, можно использовать локальный манифест:

```powershell
python scripts/optimize-menu-photos.py --manifest "C:\path\to\manifest.json"
```

Аргумент `--manifest` можно передать несколько раз. Формат манифеста: `{"assets":[{"url":"https://…/orig","path":"C:\\path\\original.jpg"}]}`. Отсутствие оригинала по умолчанию вызывает ошибку; `--allow-current` явно разрешает использовать имеющийся файл сайта, сохраняя его прежний URL источника. Для повторного сжатия лучше снова брать оригиналы.
