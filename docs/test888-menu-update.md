# Обновление групп и синхронизации остатков — 30 сентября 2026

Архив предназначен для уже работающего test888.ru. Он обновляет код сайта и админки; учётные записи, пароли, подключения КДС и заказы в архив не входят.

## Загрузка на REG.RU

1. Сохраните резервную копию текущих папок test888.ru и vosem-utra-private.
2. Распакуйте ZIP. Содержимое папки site загрузите в /www/test888.ru с заменой одноимённых файлов.
3. Содержимое vosem-utra-private загрузите в соседнюю существующую папку /www/vosem-utra-private, также с заменой одноимённых файлов.
4. Обновите страницу админки через Ctrl+F5. Вход остаётся прежним.

Не удаляйте папки на хостинге целиком. Включите показ скрытых файлов для загрузки .htaccess. В корне сайта должен находиться app.php, без дополнительной вложенной папки site.

Архив не заменяет admin-config.php, admin-data, kds-config.json, orders-config.php, kds-data и данные заказов. Действующую задачу kds-worker.php оставьте включённой. Для этого обновления не требуется запуск импорта или дополнительная выгрузка меню.

## Что изменилось

- Новые блюда поступают только из базы кассы. Ручного добавления больше нет.
- «Категории» называются «Группы». Группы сайта одноуровневые; дерево кассы сохраняет вложенность.
- «Редактировать группы» открывает список: добавляйте, удаляйте и перемещайте группы вверх или вниз. Порядок списка станет порядком на сайте после сохранения.
- Размещение блюда определяется полем «Группа на сайте». Отдельные флажки и ручной порядок блюда убраны. При обновлении все блюда с назначенной группой считаются размещёнными, включая ранее скрытые флажком.
- Переключатель «На сайте / На кассе» стал компактнее.
- Кнопка «Синхронизировать стоп-лист и остатки» обновляет ограничения из кассы. При сбое связи предыдущие данные сохраняются.

Перед изменением старого формата меню сервер автоматически создаёт резервную копию в закрытой папке admin-data. Если раньше на сайте были вложенные ручные группы, они станут самостоятельными: блюда останутся в своих группах.

## Проверка после загрузки

Откройте «Редактировать группы», проверьте названия и порядок, затем откройте несколько блюд из раздела «На кассе». Назначенная группа сайта не меняет исходную группу кассы.

Для синхронизации нужен настроенный закрытый файл подключения и доступ хостинга к адресу КДС. После успешного запроса появятся время обновления и отметки в карточках. Это ручное обновление ограничений: новые блюда оно не загружает.

Перенос на новый стенд 192.168.2.126 этим архивом не выполняется: нужны сервисные данные нового стенда и маршрут до него. Частный адрес локальной сети сам по себе недоступен серверу REG.RU. Пока новый стенд не подключён, кнопка использует текущее действующее подключение, если оно настроено.

Тестовый сайт остаётся закрыт от индексации; Telegram в этой сборке не используется.
