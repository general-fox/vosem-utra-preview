## Перед будущей публикацией

Локальный Vite читает сохранённое PHP-меню для разработки, а сборка использует
`public/data/menu.json`. На существующем хостинге рабочее меню хранится в
`vosem-utra-private/admin-data/menu.json`; обновление кода не должно заменять
эту папку или её фотографии.

В архиве обнаружена более новая версия интерфейса админки. Действующий
`vosem-utra-private/app/templates/admin.html` подключает:

- `vosem-utra.ru/assets/admin-twxUVMEW.js`;
- `vosem-utra.ru/assets/admin-CnWFxgN5.css`.

Другие файлы `admin-*` в архиве не являются активной версией этого шаблона.
Серверная админка содержит выбор подгруппы напитка с раскрывающимся списком,
фильтры и группировку напитков, а также оформление всех select-полей.
Эти изменения отсутствуют в текущих локальных исходниках. Редактор названий
и порядка подгрупп уже присутствует локально.

**При будущей сборке нельзя откатить серверную админку старым локальным JS.**
Исходники последней версии клиентского интерфейса админки архивом не
предоставлены: есть собранные assets и серверный HTML-шаблон. Перед выпуском
нужно получить соответствующие исходники либо сохранить точный действующий
серверный шаблон вместе со всеми подключёнными им assets и зависимостями.
Нельзя заменять один JS-файл отдельно от совместимого HTML и CSS.

Дополнительные интерфейсы админки в рамках импорта не реконструировались,
локальные `admin.html`, `admin.css`, `admin.js` и связанные модули не менялись.
Финальный deploy ZIP для домена сейчас не выпускается: пользователь планирует
запросить его после будущего редизайна. Проверочные сборки не являются готовым
пакетом для замены действующего сайта.
