# Сверка с сайтом от 20 ноября 2026

Источник — переданный владельцем архив `BCKP20.11.zip`, каталоги
`vosem-utra.ru` и `vosem-utra-private`. За основу взят актуальный `origin/main`
на коммите `88361da`; в нём уже находились новые акции, галереи и поля КБЖУ.
Используются редактируемые исходники проекта, а не скопированные минифицированные
сборки. Режим по умолчанию — каталог без доставки и корзины.

## Результат сверки

- Главная страница и админка собираются в те же JS/CSS, которые подключены
  действующими шаблонами из архива. Различия в лицензиях и хеше favicon
  объясняются переносами строк; внешний вид от этого не меняется.
- Серверный код PHP и API регистрации совпадает с архивом после нормализации
  переносов строк. Настройки окружения и ключи хостинга не копировались в исходники.
- Публичный снимок `public/data/menu.json` — 57 опубликованных позиций,
  пять категорий, ревизия 137 из серверного шаблона. Галереи, составы, КБЖУ,
  аллергены, объёмы и цены сохранены.
- В локальную админку перенесено полное меню из архива: 66 позиций,
  включая девять скрытых. Его файл — `.data/php-runtime/admin-data/menu.json`.
  Локальные аккаунты, пароли и настройки интеграций сохранены.
- Все фотографии, на которые ссылаются эти позиции, уже находились в
  `public/menu-images/` и совпали с архивом побайтово. Старые фото не удалялись.
- `public/data/drinks.json` — прежний справочник импорта напитков; это не
  рабочее меню. Он совпал с архивом и не заменялся содержимым админки.

## Продолжение работы

Запуск на этом компьютере — `npm run dev`, адрес из терминала обычно
`http://127.0.0.1:5173/`. Главная страница, меню и локальная админка работают
с актуальным каталогом. Изменения в исходниках видны без пересборки.

Локальная форма регистрации остаётся предпросмотром: она не создаёт гостей
в FlexBonus и не инициирует реальные звонки. Серверная форма в
`hosting/legacy-public/` сохраняет действующую интеграцию FlashCall/FlexBonus.

Сборка `npm run build` использует публичный снимок меню, а Vite и локальная
админка — закрытое рабочее меню. Позднейшие правки в админке сами в GitHub
не попадут: перед выпуском публичный снимок следует обновлять отдельно.
На другом компьютере GitHub даёт весь опубликованный каталог с фотографиями;
скрытые позиции и доступы переносятся только отдельным приватным архивом.

Из резервной копии не публиковались API-ключи, настройки SMTP, пароли,
сессии, журналы согласий/регистраций и сведения о гостях. Архив хостинга
и извлечённые приватные файлы остаются в игнорируемой `.data/`.
Сайт на REG.RU этой синхронизацией не обновляется.
