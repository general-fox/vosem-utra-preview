# Изображения текущего сайта

Инвентаризация 29 сентября 2026. Изменение структуры проекта не меняет дизайн
или кадрирование. Изображения предоставлены заказчиком; фотографии блюд каталога
описаны отдельно в `menu-photo-sources.json`.

| Блок | Используемые файлы в `assets/` |
| --- | --- |
| Первый экран — две чашки и меню | `hero-two-cups-720.webp`, `hero-two-cups-1254.webp` |
| «Сначала — кофе» — чашки с художественным размытием | `coffee-soft-720.webp`, `coffee-soft-853.webp` |
| «Потом — завтрак» | `breakfast-wide-720.webp`, `breakfast-wide-1254.webp` |
| «И что-нибудь к чаю» — сырники | `syrniki-wide-720.webp`, `syrniki-wide-1254.webp` |
| «Можно просто быть собой» — бариста | `cafe-barista-large-640.webp`, `cafe-barista-large-972.webp` |
| Контакты — вывеска | `cafe-sign-enhanced-720.webp`, `cafe-sign-enhanced.webp` |

В первом экране сохраняются исходная композиция с двумя чашками и часы работы
поверх фото. Наклона и параллакса у первого экрана нет.
Фото в «Сначала — кофе» имеет кадрирование `50% 78%`, чтобы обе чашки оставались
видны; исходное художественное размытие сохранено.

Завтрак и сырники ранее расширены встроенным ImageGen до квадратного общего
плана с пространством вокруг тарелок. Это AI-обработка, не неизменённые оригиналы.
Текущее статичное увеличение `scale: 1.4` выбрано по уточнению заказчика;
параллакс ограничен, чтобы блюда не смещались резко.

Бариста и вывеска — иллюстрации, не документальные фотографии интерьера.
Вывеска ранее улучшена ImageGen с сохранением композиции и логотипа.
WebP подготовлены без увеличения разрешения веб-версий; `srcset` выбирает
подходящий размер. Начальная фотография загружается приоритетно, остальные — лениво.

`public/social-cover.webp` — копия текущего главного изображения для карточек
ссылок; отдельный стабильный адрес необходим для метаданных сайта.
