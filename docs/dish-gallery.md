# Несколько фотографий блюда

В редакторе блюда или напитка можно добавить до 10 фотографий JPG, PNG или WebP.
Кнопка выбора файлов позволяет выбрать несколько сразу; новые снимки добавляются
к уже выбранным. Большие фотографии автоматически подготавливаются для сайта.

Первая фотография — обложка. Порядок меняется перетаскиванием пронумерованных
миниатюр мышью или пальцем на телефоне и планшете. Крестик удаляет отдельный снимок.
С клавиатуры можно менять порядок стрелками влево/вправо, Home и End.
После выбора и изменения порядка нажмите «Сохранить блюдо».

На телефоне и планшете фотографии листаются горизонтальным свайпом.
На компьютере перемещайте мышь влево или вправо по фотографии карточки:
каждая часть изображения соответствует одному снимку. Стрелок на карточке нет.
Когда мышь покидает фотографию, после такого просмотра возвращается обложка.
Точки внизу показывают число снимков и позволяют выбрать нужный; выбор точкой
или с клавиатуры сохраняется. Для клавиатуры доступны стрелки влево/вправо,
Home и End. В открытом окне блюда работает тот же просмотр: наведением мыши,
свайпом, точками или с клавиатуры; кнопок-стрелок нет.
Карточки блюд и напитков, а также фотографии в открытом окне блюда используют
единый горизонтальный формат 4:3 на компьютере, планшете и телефоне. Снимки
показываются целиком, без изменения пропорций. В окне блюда нет цветной подложки;
размер области фотографии остаётся одинаковым при переключении ракурсов.
При одном снимке дополнительные элементы управления не показываются.
Если фотографий нет, остаётся обычная заглушка.

## Сохранение и перенос

У блюда хранится упорядоченный массив images. Поле image сохраняется для
совместимости и содержит первый снимок. Существующие блюда с одним полем image
не требуют повторной загрузки. Пустой массив images удаляет все фото из карточки.

Файлы загружаются последовательно, а меню сохраняется после успешной загрузки всех
снимков. При ошибке загрузки черновик остаётся в открытой вкладке; уже загруженные
снимки повторно не отправляются при повторе сохранения.

Изменения нужно переносить на хостинг вместе с обновлёнными серверными
обработчиками меню. Старый обработчик, понимающий только image, не сохранит галерею.
Рабочее меню и файлы uploads не заменяют исходным каталогом при обновлении.
Приватный экспорт/восстановление проверяет наличие всех снимков галереи.

GitHub Pages показывает фотографии из опубликованного public/data/menu.json.
Локальные изменения через админку, как и раньше, не отправляют рабочие данные
автоматически в GitHub или на REG.RU.
