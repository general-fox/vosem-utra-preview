# Обновление test888.ru: сайт → КДС → касса

Это обновление уже установленного test888.ru. На сайт клиента его не загружать.
Архив содержит приватный сервисный доступ к тестовой КДС. Не загружайте архив
целиком в каталог сайта и не публикуйте его в GitHub.

## Загрузка

1. Сделайте резервную копию текущего сайта и папки vosem-utra-private средствами
   хостинга. Резервную копию храните вне публичного каталога.
2. Распакуйте этот архив на компьютере. В нём папки site и vosem-utra-private.
3. Содержимое site загрузите в текущий корневой каталог test888.ru с заменой
   одноимённых файлов, включая скрытый .htaccess. Не удаляйте каталог целиком.
4. Папку vosem-utra-private объедините с существующей одноимённой папкой
   НА УРОВЕНЬ ВЫШЕ корня сайта. Подтвердите замену файлов app.
   kds-config.json, kds-worker.php и kds-check.php должны лежать рядом с app,
   не внутри публичного каталога. Готовый доступ уже заполнен.
5. Не заменяйте и не удаляйте admin-config.php, admin-data, orders-config.php,
   orders-data. В этом архиве их нет: ваш вход, привязка аутентификатора,
   фотографии, правки меню и старые заявки сохранятся.
6. В настройках PHP сайта проверьте версию 8.3+ и расширения cURL, PDO SQLite,
   OpenSSL, GD, fileinfo; память не меньше 256 МБ. HTTPS сайта уже должен работать.

## Проверка после загрузки

Откройте https://test888.ru и обновите страницу Ctrl+F5.
Внизу меню появятся «Тест КДС · Пшенная каша с тыквой» (200 ₽)
и «Тест КДС · Сырники с малиновым вареньем и сметаной» (395 ₽).
Остальное меню остаётся на сайте, но заказ через КДС для него пока отключён.

Добавьте одну тестовую позицию, выберите самовывоз, укажите вымышленное имя
и +7 (000) 000-00-00, затем проверьте сумму и отправьте.
Дождитесь «Ожидает принятия в КДС» и номера заявки.
В точке «155 301 Боевой тест» примите именно эту заявку в работу:
сайт должен показать «Принят в КДС». Отмена тоже отражается на сайте.
Обновление страницы в том же браузере продолжает проверку этой же заявки.

Старые заявки автоматически не отправляются. В КДС записывается условная
тестовая предоплата; банковского списания нет. Готовить и доставлять не нужно.
Если ответ на создание потерян и написано «Результат отправки пока неизвестен»,
проверьте КДС перед новым заказом: автоматический повтор отключён против дублей.

## Однократно включить фоновые проверки

В ispmanager откройте планировщик заданий (cron), добавьте запуск каждую минуту.
Нужно запускать kds-worker.php из приватной папки версией PHP 8.3+ с cURL и SQLite:

```text
<путь к PHP> <полный путь к vosem-utra-private>/kds-worker.php --private-dir=<полный путь к vosem-utra-private>
```

Это шаблон, а не готовая команда: пути зависят от аккаунта REG.RU.
Чтобы получить готовую строку, сообщите путь корневого каталога test888.ru
из раздела «Сайты» и используемую версию PHP. Пароли для этого не нужны.
Если путь к PHP не указан в панели, его подскажет поддержка хостинга.

Без планировщика проверка работает при открытой странице заказа.
Планировщик нужен, чтобы отправка и проверка продолжались после закрытия вкладки.
Для каждого заказа запускать терминал не потребуется.

На рабочий сайт клиента этот тестовый режим не переносим: сначала подключаем
рабочее меню, HTTPS API и согласованную оплату/неоплаченные заказы.
Технические детали и ограничения — в kds-connection.md.
