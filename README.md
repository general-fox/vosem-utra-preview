# Восемь утра — демоверсия

Рабочая папка этой версии: `C:\vosem-utra\github-preview`.

## Локальный запуск

Требуется Node.js с npm. При первом запуске: `npm install`.

```powershell
cd C:\vosem-utra\github-preview
npm run dev
```

Откройте адрес из терминала (обычно http://127.0.0.1:5173/).
Сохранённые изменения автоматически отображаются в браузере.
Остановить сервер: Ctrl+C.

`npm run build` собирает все четыре страницы в `dist`.
`npm run preview` позволяет посмотреть эту сборку локально.
Относительные пути подходят для размещения сайта в подпапке GitHub Pages.
Также страницы работают как обычные статические файлы из корня репозитория.

## Что редактировать

- `index.html` — главная страница и тексты.
- `style.css` — фирменные цвета, общие компоненты, главная и мобильная версия.
- `registration.html`, `registration.css` — страница клуба гостей.
- `registration.js` — маска телефона и логика формы.
- `privacy.html`, `consent.html`, `legal.css` — правовые документы и их оформление.
- `site.js` — мобильная навигация и согласованное появление текста, фотографий,
  карточек и декоративных блоков. Цели отмечены `data-reveal` в HTML.
  Начальное состояние задаётся до первой отрисовки: нет вспышки «видно → скрыто».
  Появление запускается один раз при входе в экран, задержки внутри группы
  не превышают 180 мс. Фотографии декодируются перед появлением карточки.
  Если основной скрипт не загрузился, предохранитель открывает содержимое
  через 1,6 секунды. Фокус, якорные ссылки и возврат из истории не ждут анимации.
  Анимации отключаются при настройке «Уменьшение движения»; без JavaScript
  всё содержимое остаётся видимым. Поля формы не анимируются.

GitHub Pages не исполняет PHP. В этой копии форма явно помечена
`data-preview="true"`, кнопка отключена, обработчик не отправляет данные.
Для настоящей регистрации потребуется серверная версия из `../site`.
Изменения этой демоверсии не синхронизируются в `../site` автоматически.

`assets/cafe-sign-enhanced.png` — улучшенная встроенным ImageGen версия
исходного `assets/cafe-sign.png` (исходник сохранён без изменений).
Готовое изображение: 1254 × 1254. Для сайта используются WebP-версии

Промпт обработки (встроенный инструмент, без API/CLI):

Enhance the existing image only: restore crisp, natural detail, remove softness and compression, render at a high resolution suitable for retina displays (approximately 2048 x 2048). Preserve the exact square crop, perspective, lightbox shape and position, dark frame, red-brown brick facade, window edges, warm understated illumination and original atmosphere. Preserve the brand wordmark exactly as shown, including its particular elegant black serif letterforms; text verbatim in Cyrillic: "Восемь утра". No text replacement, no extra letters, no new objects, no redesigned architecture. Refine brick texture and frame edges gently without oversharpening or halos. Do not change the scene or add artistic stylization. Output only the enhanced existing image, not a comparison or a mockup.

### Перед включением настоящей регистрации

Это оформление интерфейса, а не подтверждение юридической готовности сервиса.
Оператору/юристу нужно согласовать тексты и фактические процессы: состав данных,
цели и сроки, хостинг и журналы сервера, CRM/программа лояльности, получатели,
локализация баз данных и необходимость уведомлений Роскомнадзора.
Факт получения согласия и его версию необходимо фиксировать на сервере;
сервер должен отклонять анкету без согласия. В демоверсии backend отсутствует.

В `registration.js` сохранена неактивная логика Google reCAPTCHA из серверного
сайта. Сейчас она не загружается благодаря `data-preview="true"`. Нельзя просто
включить её без отдельной проверки передачи данных и cookie. После выбора
хостинга нужно проверить его заголовки Set-Cookie и фактические запросы сайта.
При добавлении необязательной аналитики/рекламных сервисов, работающих на
основании согласия, их загрузка должна происходить только после явного выбора;
нужны равнодоступные отказ и отзыв выбора, а не только кнопка «Понятно».
Обновите раздел cookie до подключения таких сервисов.

Правовые ориентиры, проверенные 18.09.2026:

- [152-ФЗ, статья 18.1: доступ к политике](https://www.consultant.ru/document/cons_doc_LAW_61801/eeeebe22bf738fd65bb66b95cc278911ae2525ee/).
- [152-ФЗ, статья 9: отдельное согласие и доказательство его получения](https://www.consultant.ru/document/cons_doc_LAW_61801/6c94959bc017ac80140621762d2ac59f6006b08c/).
- [152-ФЗ, статья 6: основания обработки](https://www.consultant.ru/document/cons_doc_LAW_61801/315f051396c88f1e4f827ba3f2ae313d999a1873/).
