Lato webfont packaging

Original font author: Lukasz Dziedzic. License: SIL Open Font License 1.1.
See Lato-OFL.txt for the original copyright, Reserved Font Name and license.
The original TTF files are retained in the repository assets/ for reproducible
packaging. They are not downloaded by the site or included in the hosting package.

The Regular, Medium and Italic WOFF2 files contain the full character inventory
of their corresponding TTFs, including Cyrillic. No subsetting, glyph changes,
hint removal or OpenType feature removal was performed. Names, author and
license metadata are preserved. FontTools removes the empty DSIG placeholder
and updates the container checksum and WOFF2 compression flag.

Generation: scripts/compress-fonts.py using FontTools 4.65.0 and Brotli 1.2.0.
The script compares all retained table bytes (normalizing only the checksum
and compression flag), character maps and advance metrics with the originals.
To reproduce: install fonttools[woff], then run python scripts/compress-fonts.py --originals.
The website now uses renamed, unhinted Vosem Sans derivatives; see VosemSans-WOFF2.txt.
