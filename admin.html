УПРАВЛЕНИЕ МЕНЮ

Рады видеть вас

Войдите, чтобы добавлять блюда, обновлять фотографии и цены.

Вход пока недоступен. Обратитесь к администратору сервера, чтобы подготовить защищённое подключение.

Подтверждение входа

В Яндекс ID (Ключ) выберите «Восемь утра» и введите 6 цифр. Код можно вставить целиком.

1 из 3 · Данные для входа

Эта почта станет вашим логином для следующих входов.

Можно оставить текущий пароль или задать новый — не менее 15 символов.

2 из 3 · Подключение телефона

  1. Откройте Яндекс ID (Ключ) и добавьте аккаунт.
  2. Отсканируйте QR-код. Выберите запись «Восемь утра».
  3. Введите шестизначный код из этой записи ниже.

Ввести ключ вручную

Добавьте аккаунт «Восемь утра» с этим ключом. Тип: TOTP, 6 цифр, 30 секунд, SHA-1.

Подключение завершится только после проверки кода.

3 из 3 · Сохраните доступ

Эти коды показываются один раз. Сохраните их в менеджере паролей: они помогут войти без телефона. Каждый код действует один раз после ввода пароля.

    Доступ только для команды кофейни.
